# AI Object Detection System

A beginner real-time object detection project using Python, OpenCV, and a pretrained YOLOv8 model.

## Features
- Real-time webcam object detection
- Bounding boxes and labels
- FPS display
- Uses pretrained YOLOv8 model

## Technologies Used
- Python
- OpenCV
- Ultralytics YOLOv8

## How to Run

Install dependencies:

pip install -r requirements.txt

Run webcam detection:

python webcam_ai.py

Press 'q' to quit.
